## 📌 Repository Overview

This repository contains the coursework and lab implementations for **SENG 300: Software Data Structures and Algorithms**. 

Assignment 2 focuses on fundamental node-based data structures, specifically contrasting custom singly linked list implementations with the standard Java Collections Framework (`java.util.LinkedList`):
1. **Custom Linked List Internals:** Building, traversing, inserting, and deleting nodes using pointer/reference manipulation.
2. **Java Collections Framework (JCF):** Utilizing built-in `LinkedList` utility methods for element insertion, index-based and key-based removal, and client-facing list operations.
