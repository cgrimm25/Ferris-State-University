## 📌 Repository Overview

This repository contains the coursework and lab implementations for **SENG 300: Software Data Structures and Algorithms**. 

Assignment 1 focuses on two foundational software engineering concepts:
1. **Object-Oriented Programming Structure:** Demonstrating interface contracts, class implementations, encapsulation, and driver testing in Java.
2. **Algorithm Execution & Benchmarking:** Implementing a dataset generator and testing empirical execution time with **Selection Sort** using unsorted numeric inputs.
